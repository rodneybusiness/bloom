# Life 101: Mastering Your Own Curriculum · Course Syllabus

> This syllabus defines everything you will be able to do after completing this course.
> Learning depth: Deep
> Source: your RemNote base "Answering Questions + Life 101" (~1,500 prompts across four branches), fully analyzed in [source-map.md](./source-map.md). The number of lessons varies; the mastery items do not get watered down.

## Core Mastery Items

After completing this course, you will be able to:

### 1. The Architecture — know what you built
- [ ] Able to describe the three-altitude structure of the base (how the world works / how to think about it / how to operate in it), and place any given card at its altitude
- [ ] Able to state the unifying thesis of the whole base and trace it through one concrete card from each of the three branches
- [ ] Able to explain what the base's *proportions and emphases* reveal about its real purpose (59% thinking-and-acting; defensive over generative; dispositions installed as flashcards)

### 2. The Seven Deep Patterns — own the spine
- [ ] Able to state each of the seven patterns (entropy/maintenance, compounding, mechanism-over-appearance, the miscalibrated mind, incentives/de-bundling, pre-commitment, trade-offs/scale) and give one instance of each from each altitude
- [ ] Able to take any new fact, decision, or card and identify which pattern(s) it instantiates — or argue that it instantiates none
- [ ] Able to explain the meta-pattern that reconciles the base's central tension: judgment is provably unreliable AND you are radically responsible — because agency is exercised through systems, not willpower
- [ ] Able to state the five unstated identities the base sets up (natural selection ≡ incentives; homeostasis ≡ negative feedback; entropy ≡ maintenance; compound interest ≡ habit; genes ≡ writing ≡ money ≡ code) and defend one of them against a skeptic

### 3. Operational Command — run the machine cold
- [ ] Able to reproduce the load-bearing priority orders and thresholds (money order, FICO weights, danger zone, 3-2-1, 60% rule, 50% rule, 4% rule, 5% rule) — and, more importantly, re-derive the *reason* behind each order
- [ ] Able to run the base's decision frameworks on fresh cases (rent vs. buy, repair vs. replace, finance vs. cash, deductible choice, when-to-get-a-lawyer) and state the conditions under which each framework breaks
- [ ] Able to answer any question from the Kids branch at three depths (young child / teen / adult) using the base's answering method: negate the folk belief, give the mechanism, label epistemic status, map-not-verdict on values

### 4. Critique and Repair — audit what spaced repetition would make permanent
- [ ] Able to explain the top defects in the defect ledger (ground poultry 165°F, the 2-2-2 contradiction, the I-105/Northridge chronology, the vacated salary threshold, stale tax vintages) and why each matters
- [ ] Able to audit any card in four checks — well-formed syntax? testable prompt? correct content? honest hedging? — and fix a failing card in correct RemNote form
- [ ] Able to rank the gap ledger (Bayesian updating, wildfire/first-aid/remediation, the generative finance half, the unfinished 109 questions) by expected value and defend the ranking

### 5. Teaching It Forward — the point of the whole project
- [ ] Able to write new cards in the base's house style, matching card form to knowledge type (concept ↔ / Q→A / cloze / verbatim script), including one complete new topic ready to import
- [ ] Able to design the completion plan for the base: what to convert, what to fix, what to add, what to delete, in what order — turning the 70%-built snapshot into a finishable project

## Not Covered in This Course

- Verifying every factual claim in the base against primary sources (the defect ledger flags known errors; a full fact-audit is a separate project)
- Financial, legal, or medical advice — the course teaches what *your base* claims and where it's known-wrong; decisions stay yours
- RemNote software mechanics beyond card syntax (plugins, sync, scheduling algorithms)
- The philosophical literatures behind the base's sources (Taleb, Harari, Stoicism) beyond what the cards themselves use
